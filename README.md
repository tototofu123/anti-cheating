# Anti-Cheating System 🛡️👨‍🏫

An AI-monitored anti-cheating system designed for online exams. It features real-time violation detection and comprehensive session monitoring to ensure academic integrity.

## 🚀 Key Features
- **Violation Detection**: Automatically identifies suspicious activities during exam sessions.
- **Session Tracking**: Logs session data for post-exam review.
- **Web Interface**: Easy-to-use dashboard for monitoring exam status.
- **Privacy-First**: Designed to focus on behavior patterns rather than sensitive personal data.

## 🛠️ Tech Stack
- **JavaScript (Vanilla)**
- **HTML5 & CSS3**
- **GitHub Pages** for deployment

## 📂 File Structure
- `app.js`: Main logic for monitoring and violation detection.
- `config.js`: Configuration settings for the detection engine.
- `index.html`: User interface for the proctoring dashboard.
- `utils.js`: Helper functions for data processing and logging.

## 📖 How to Use
1. Deploy the project to a static host (e.g., GitHub Pages).
2. Integrate the tracking script into your online exam platform.
3. Monitor the session logs via the provided dashboard.
